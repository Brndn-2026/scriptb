# Welcome to BScript

Welcome to BScript(made in python)
An example script of printing hello bscript then waiting 3 secs then saying hello world 3 times:

main.bscript:

print hello bscript

wait 3

repeat 3 print hello world

# How to run
run main.bat to run the reguler main.bscript

run bscript.exe to run the REPL(use runfile filepath to run a .bscript file)

run bscript.exe filepath(run in terminal) to run the file

all the docs will be in the wiki
