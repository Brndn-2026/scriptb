# ScriptB Roadmap

This is a proposed, beginner-first direction, not a release schedule.

## First priorities

- Publish a verified language reference with runnable examples for each supported command.
- Add small automated tests for documented syntax and error cases.
- Make the interpreter source and reproducible build instructions easy to find in the canonical repository.
- Keep the Windows download, README, docs, and website links consistent.

## After the basics

- Add a beginner tutorial that grows one script step by step.
- Set up issue templates and a place for users to share small scripts.
- Consider automation or IoT examples only after the language's core behavior and safety boundaries are documented.

Priorities should change in response to user feedback and confirmed interpreter capabilities.
