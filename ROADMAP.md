# Roadmap

These are suggested priorities based on the interpreter's current state, not dated commitments.

1. Keep the quick start, command reference, and examples aligned with behavior that can be run.
2. Add automated regression tests for existing commands and error cases; there is not yet a maintained automated suite.
3. Make command argument parsing and diagnostics more consistent, especially around spaces and quoting.
4. Document and verify the supported runtime and packaging platforms instead of assuming the Windows executable's behavior applies elsewhere.

Ideas such as a formal grammar or broader language features remain exploratory until they are proposed and evaluated.
