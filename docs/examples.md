# ScriptB Examples

Run examples from PowerShell in the project folder with:

```powershell
.\scriptb.exe .\example.bscript
```

## Included scripts

| File | What it demonstrates |
| --- | --- |
| `example.bscript` | Prints a short message. |
| `main.bscript` | Prints a welcome and repeats a greeting three times. Run it with `main.bat`. |
| `test.bscript` | A broad command probe; not a tutorial or a formal specification. |

For the smallest working program, see the [quick start](quickstart.md). For syntax notes, see the [reference](reference.md).
